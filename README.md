## 現職での主な実績

- 現場業務を iPhone 1台で回す社内スーパーアプリ (9機能) のフロントエンド全域を設計・実装し、全社200名以上が利用
- BLE サーマルプリンター連携の納品機能 — 操作から納品書印刷完了まで2秒以内
- 品質はレビューの頑張りではなく環境で担保する方針 — 設計規約の機械的強制 + Playwright 受入検証ハーネス

※業務コードは非公開のため、公開リポジトリは実務同様の設計思想・検証スタイルで個人開発した成果物です。
